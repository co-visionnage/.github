# notrecinema

Семейный трекер фильмов и сериалов: общий список на всю семью, у каждого свои
оценки и прогресс, голосования «что смотрим сегодня», встречи для просмотра,
уведомления и еженедельная сводка.

## Репозитории

| Репозиторий | Что внутри |
|---|---|
| [co-visionnage-app](https://github.com/co-visionnage/co-visionnage-app) | Фронтенд: Next.js, TypeScript |
| [notrecinema-api](https://github.com/co-visionnage/notrecinema-api) | HTTP API на Go |
| [notrecinema-worker](https://github.com/co-visionnage/notrecinema-worker) | Воркер на Go: письма и push |
| [database](https://github.com/co-visionnage/database) | Схема БД и миграции |
| [notrecinema-infra](https://github.com/co-visionnage/notrecinema-infra) | Развёртывание сервера (Ansible), мониторинг |
